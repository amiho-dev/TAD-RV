# Admin/Teacher Guide

Dieses Handbuch ist fuer den Unterrichtsalltag gedacht.

## Start in 60 Sekunden

1. TADAdmin starten.
2. Verbundene Schueler im Grid pruefen.
3. Bei Bedarf Game Filter oder Web-Lock aktivieren.
4. Fuer Erklaerphasen Freeze einsetzen.
5. Nach der Stunde alle Sperren aufheben.

## Wichtige Bedienflaechen

- Student Grid: Online-/Offline-Status und Live-Thumbnails
- Actions: zentrale Steuerbefehle
- Settings: Sprache, kompakte Toolbar, Anzeigeoptionen
- Room-Auswahl: Szenarien je Klassenraum

## Filter im Unterricht

- Game Filter On: bekannte Spiele/Launcher blockieren
- Game Filter Off: globale Spielsperre zuruecknehmen
- Program-Lock/Web-Lock: gezielte Fokussteuerung

## Datenschutz im RV

Passwortbereiche werden vor dem Versand maskiert. Bei problematischen UIA-Faellen greift ein Fallback fuer typische Login-Fenster.

## Troubleshooting

| Problem | Schnellcheck |
| --- | --- |
| Keine Schueler sichtbar | Netzwerksegment, Client-Dienst, Firewall |
| RV stockt | Bandbreite, gleichzeitige Sessions reduzieren |
| Sperre wirkt nicht | Client online? Verbindung stabil? |
