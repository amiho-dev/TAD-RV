# Emulation Guide

Emulation ist fuer Demo, Entwicklung und Schulung gedacht.

## Zweck

- UI und Workflows testen, ohne komplette Produktionsumgebung
- Team-Schulung ohne Risiko fuer reale Klassenraeume
- Schnelltests von Dashboard- und Deploy-Funktionen

## Wichtig

Emulation liefert keine echte Schutzwirkung. Sie eignet sich nur fuer Funktions- und Ablaufpruefung.

## Empfohlene Nutzung

1. Emulierten Service starten.
2. Domain Controller und Admin UI verbinden.
3. Sperren, Filter, Logs und Updatehinweise pruefen.
